# 10 · Getting Started

This section is the fastest way to become productive with the openEO Python client. It covers the basics of connecting to a backend, authenticating, creating a small datacube, and running a first processing workflow.

## What you will learn

- how to connect to an openEO backend
- how to authenticate and access collections
- how to build a simple processing workflow with Sentinel-1 or Sentinel-2 data
- how to inspect and download a result from a batch job

## Notebook

| Notebook | What it teaches |
|---|---|
| [getting-started.ipynb](./getting-started.ipynb) | Connect to a backend, authenticate, process a small Sentinel-2/Sentinel-1 example, and run a first batch job. |
